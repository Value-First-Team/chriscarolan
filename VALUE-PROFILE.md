# chriscarolan — Value Profile

## 1. Value Specification

A live, fully-built one-page Astro site at chriscarolan.com — hero, proof row, problem
statement, how-he-helps, comparison card, Value-First Team cross-link, bio, speaking/media
reel, podcast section, downloadable speaking kit, and a booking CTA. Built on `@vf/design-engine`,
`@vf/site-kit`, `@vf/ui` and `@vf/brand`, deployed on Vercel.

## 2. Declared Value

This site exists so a person who encounters Chris directly — a stage, a podcast, a LinkedIn
post, a referral — has one place to go that answers "who is this person and can I trust him,"
independent of whether they've ever heard of Value-First Team. It carries his personal brand
(speaking, media, book) and hands off to the firm (`valuefirstteam.com`) and the booking flow
rather than duplicating either.

## 3. Value Omissions

Not a blog, not a course, not a client portal — those live on `valuefirstteam.com` and the
Academy surfaces. Not the show pages (`ainativeshift.com`, `valuefirstteam.com/shows`) — this
site links out to them rather than hosting them. No CMS content model; every section is a
hand-authored component, not a data-driven registry.

## 4. Value Wake (derived)

Live and actively maintained — recent commits ship a fly-in nav layer, HubSpot visitor
tracking, and repeated design-system repins (`@vf/ui`, `@vf/brand`, `@vf/design-engine`),
so it is receiving real design-system value as the shared engine evolves. Direct booked
relationship value from this specific URL (vs. the firm's own booking funnel) is unbooked —
no Value Entry traces a lead or a booked call to chriscarolan.com specifically.

## 5. Value Trajectory

**Capability** — the surface is built and current, consuming the shared design system as it
matures. It moves toward multiplication if it becomes a real distribution channel in its own
right (an SEO/referral entry point that measurably feeds the booking funnel), which is not yet
instrumented or confirmed.

## 6. Value Gap & Verdict

Declared (a standalone authority front door) and derived (a live, current, on-brand site) are
not in tension — the gap is instrumentation, not scope: whether this specific URL is actually
converting a stranger into a booked call is not yet measured anywhere. **Verdict: keep** — it is
live, maintained, and serves a real distinct role from the firm site; the open item is wiring a
Value Entry / attribution path so its wake stops being unbooked by default.
